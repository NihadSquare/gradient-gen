# Security policy

## Supported versions

Only the latest release and the current `main` branch receive fixes.

## Privacy by design

Gradient Gen runs completely in your browser. It does not send your pictures, logos, palettes or settings anywhere. Presets and saved palettes stay in your browser's local storage.

## Report a vulnerability

Please do **not** open a public issue for a security problem.

1. Go to the repository's **Security** tab.
2. Choose **Report a vulnerability** and describe the problem, how to repeat it, and which browser you used.

The maintainer will answer within a few days and will tell you when a fix is published. If you cannot use that form, contact the maintainer through the details on the [GitHub profile](https://github.com/NihadSquare).

Examples of what is in scope: a way to run script through an imported preset, palette or image file; a way to make the app send data to another site.
